Release of the Behavioral State Protocol specification.

## Breaking changes

- **A2A transport binding removed.** The `a2a` transport block, the `a2aTransport` schema definition, and the `push.a2a` delivery channel are gone from the discovery manifest schema (`additionalProperties: false` means manifests declaring `a2a` no longer validate). BSP keeps HTTP (baseline) and MCP as consumer-facing bindings, plus optional gRPC. Rationale: A2A is itself HTTP/JSON — A2A-speaking agents already reach BSP services through the HTTP binding — and the mapping dragged in A2A's task lifecycle, a coordination model BSP deliberately does not own. See [Design Decisions — A2A Transport removed](https://github.com/behavioralstate/spec/blob/spec/v0.8.0/specs/design-decisions.md#a2a-transport-removed).

## Additions

- **Security: Credential Passthrough at Intermediaries.** New normative section in [specs/security.md](https://github.com/behavioralstate/spec/blob/spec/v0.8.0/specs/security.md#credential-passthrough-at-intermediaries) covering intermediaries (MCP servers, gateways, multi-user backends) that forward per-caller credentials upstream: passthrough MUST be opt-in per connection, forwarded only to the configured endpoint over TLS, explicit per-request credentials take precedence over ambient Authorization headers, credentials are never logged, and multi-user deployments SHOULD fail closed. Implemented by `@behavioralstate/bsp-mcp` 1.7.0 (`allowBearerPassthrough`).

Protocol version (`version.json`): 0.8.0.
