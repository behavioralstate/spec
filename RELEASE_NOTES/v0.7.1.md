## Breaking changes

- **Local service registry removed.** The `agents/registry.json` schema is deleted and the registry is no longer a protocol capability. `serviceDescriptor` is now defined inline in `discovery.json`, and the manifest's `agents` array is a discovery hint only — not a live directory; the protocol defines no registry endpoint. Implementations that manage services dynamically expose that as a domain under their own namespace (e.g. a list-services query and a `RegisterService` command). Registry and lifecycle docs, discovery examples, the OpenAPI document, and the MCP server are updated accordingly. Manifests or implementations that relied on the registry capability no longer validate.

*Published retroactively — this release originally shipped without notes.*
