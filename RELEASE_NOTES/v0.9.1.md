## Security — command authorisation (normative)

- Per-command authorisation policies are required for each credential, service, and role; enforcement is deny-by-default and empty policies are prohibited.
- Actor fields inside `data` must never be trusted as authenticated identity — servers reject them or overwrite them from the authenticated context.

## Schema selection relaxed

- Servers may key schema lookup by any server-owned identifier — the CloudEvent `type`, or the catalogue name carried in `dataschema` — rather than requiring the absolute catalogue-URI form on ingest. The security control is unchanged: never dereference a caller-supplied URI.

## Tooling & standards track

- `best-validate`: executable conformance checker for live endpoints, published to npm with its own `validate/v*` release pipeline.
- Standards-track artifacts: IANA well-known URI registration template and Internet-Draft skeleton; `ROADMAP.md` added.
